== Description

A set of ready-to-use collections for PHP.

The main goal of this library is to provide a set of reusable, independent, standalone collections classified by their
features and intended use scenarios. It is developed as an alternative to using specific collections from much bigger
libraries whose focus is on a completely different feature set, but have collections implemented as an internal
requirement.

In short, if your project needs support for collections, but you don't need DoctrineORM (or any other software package
that has collections), this library is for you.

== Installation

[source]
----
composer require constup-foss/php-collections
----
